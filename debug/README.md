# Debug Directory

This directory contains debugging tools and test interfaces for development purposes.

## Debug Files

### Authentication Debugging
- `debug-auth.html` - Authentication system debugging interface

### Job System Debugging
- `debug-job-application.html` - Job application process debugging
- `debug-job-posting.cjs` - Job posting functionality debugging (Node.js)

### Service Debugging
- `debug-service-posting.html` - Service posting system debugging

## Usage

These debug files provide interfaces for developers to test and troubleshoot specific application features during development. They can be opened in a browser or executed with Node.js (for .cjs files) to debug various components of the system.
