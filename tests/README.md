# Tests Directory

This directory contains test files for various components and features of the application.

## HTML Test Files
Test files for UI components and frontend functionality:
- `test-auth-*.html` - Authentication system tests
- `test-frontend-*.html` - Frontend component tests
- `test-job-*.html` - Job-related functionality tests
- `test-registration*.html` - User registration tests
- `test-resume-*.html` - Resume handling tests
- `test-enhanced-*.html` - Enhanced features tests
- `test-analytics-insights.html` - Analytics system tests
- `test-assessment-system.html` - Assessment functionality tests
- `test-interview-workflow.html` - Interview process tests
- `test-profile-management.html` - Profile management tests
- `test-recruiter-applications.html` - Recruiter dashboard tests
- `test-smart-automation.html` - Automation features tests

## JavaScript Test Files
- `test-complete-auth.js` - Complete authentication flow tests
- `test-frontend-service-creation.js` - Service creation tests
- `test-frontend-auth.cjs` - Frontend authentication tests (CommonJS)

## Quick Tests
- `quick-auth-test.html` - Rapid authentication testing

## Usage

These test files can be opened in a browser or run through the testing framework to validate application functionality.
