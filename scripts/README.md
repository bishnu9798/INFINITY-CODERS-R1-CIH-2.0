# Scripts Directory

This directory contains utility scripts for managing the application:

## Batch Files for Development

### Backend Management
- `start-backend.bat` - Start the backend server
- `start-freelancer-market-place.bat` - Start the full application
- `start-freelancer-market-place-mongodb.bat` - Start with MongoDB
- `start-freelancer-market-place-stable.bat` - Start stable version
- `stop-freelancer-market-place.bat` - Stop the application

### Frontend Management
- `start-frontend.bat` - Start the frontend development server

### System Management
- `start-infinity-workspace.bat` - Start the complete workspace
- `stop-infinity-workspace.bat` - Stop the workspace
- `check-infinity-workspace.bat` - Check workspace status
- `check-system.bat` - System health check

## Usage

These scripts are designed for Windows development environments. Run them from the project root directory.
